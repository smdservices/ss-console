# AI Employee — Connector Coverage Research

**Date:** 2026-05-14
**Status:** All four vertical research agents complete
**Methodology:** Four parallel research agents. Per tool: verify Composio catalog entry directly, search MCP registries (`modelcontextprotocol/servers`, glama.ai), check vendor API docs. No guessing — every entry is verified by visiting the source.

## Purpose

Source of truth for the build-or-buy decision per SaaS connector. Drives the connector layer of the multi-tenant scaffold (#20) and the per-skill design across the 58-skill grading matrix (#18).

## Cross-vertical summary — what this means for the build plan

**Composio coverage is highly uneven across verticals.** The "Composio for connectors" decision in the stack eval (`ai-employee-stack-evaluation-2026-05-13.md`) was directionally right for marketing, partially right for two others, and effectively wrong for two. Real numbers:

| Vertical                     | Tools researched | COMPOSIO | MCP | BUILD | BLOCKED | Viability for 7-14 day beta              |
| ---------------------------- | ---------------- | -------- | --- | ----- | ------- | ---------------------------------------- |
| Marketing agencies           | 11               | 9        | 2   | 0     | 0       | **Ready — ship today**                   |
| Manufacturing                | 7                | 1        | 1   | 5     | 0       | **Ready if customer on NetSuite or BC**  |
| Real estate                  | 16               | 2        | 1   | 11    | 1       | **Ready if customer on Follow Up Boss**, MLS+TCPA add-on |
| Law firms                    | 11               | 1        | 2   | 5     | 3       | Possible but 5-10 days of MCP-wrapper work first |
| Insurance agencies           | 5                | 0        | 0   | 2     | 2       | **Not ready — partner gates 30-90 days** |

**Three categories of vertical viability for first paid beta:**

1. **Connector-ready (ship today):** Marketing agencies — Composio covers the stack; zero BUILD; the only real friction is Google Ads developer-token approval and LinkedIn Marketing API app review (vendor gates we hit on any path).
2. **Connector-conditional (ship if customer is on a covered tool):** Manufacturing on NetSuite or Business Central; real estate on Follow Up Boss + Dotloop (with MLS access as per-customer add-on); law on Clio (community MCP exists).
3. **Connector-blocked (30-90 day partner work before any beta):** Insurance on Applied Epic, HawkSoft, or AMS360 — partner programs gate API access. EZLynx is the only insurance vendor a beta could ship against quickly.

**Real product constraints discovered (these go straight into the SOW per vertical):**

- **Law:** the AI Employee does practice management, billing, signatures, and federal court records (via CourtListener). It does **not** query commercial legal-research databases (Westlaw, LexisNexis, Casetext) — those are partner-gated with per-customer licensing and real liability exposure for unauthorized queries.
- **Insurance:** customer must already have AMS API access enabled OR be willing to wait 30-90 days for partner-program approval on Applied Epic / HawkSoft / AMS360.
- **Real estate:** customer must be a licensed agent or contracted broker for MLS access (Bridge/RESO/Spark/Trestle gate). Plus A2P 10DLC brand + campaign registration is required for any agent-initiated SMS (US carriers block unregistered 10DLC since Feb 2025).
- **Manufacturing:** customers on legacy on-prem ERP (SAP B1, SYSPRO, Applied TAM in insurance) require per-customer network setup (Cloud Connector or reverse proxy). The agent cannot reach an air-gapped on-prem instance.

**Implication for first paid beta within 7-14 days.** If the beta lands quickly, the realistic verticals are:

1. **Marketing agency** — anywhere; the stack is connector-ready
2. **Manufacturer on NetSuite or Business Central** — Composio (NetSuite) or Microsoft-official MCP (BC) covers it
3. **Real estate operation on Follow Up Boss** — CRM is Composio-covered; MLS access is per-customer
4. **Law firm using Clio** — community MCP exists and is healthy; need to add 1-2 BUILDs (Filevine alternative, LawPay) for full pack

**Insurance is realistic only if the prospective beta agency already has EZLynx API enabled or is on a vendor we haven't covered (Nowcerts, Indio, etc., not researched).** Don't promise insurance betas until partner programs are in flight.

**Total BUILD work surfaced by the research:** ~5-10 days of MCP-wrapper engineering per vertical we want to make ready (Filevine + Lawmatics + PracticePanther + MyCase + LawPay for law; Acumatica + SAP B1 + SYSPRO + Fishbowl + Epicor P21 for manufacturing; Lofty + kvCORE + Dotloop + Brokermint + several others for real estate). Each wrapper is ~1-2 days. Sequence by first-beta vertical.

## Verdict legend

- **COMPOSIO** — Use Composio's managed or unmanaged toolkit. No custom code.
- **MCP** — Use an existing native MCP server (vendor-official or well-maintained community).
- **BUILD** — No existing connector. Wrap the vendor's API in a thin MCP server ourselves.
- **BLOCKED** — No usable integration path. Licensing, partner-only access, or no public API. Customers using these tools cannot be served until the gate opens.

- **Total integration build cost for the law vertical:** ~5-10 days of MCP-wrapper engineering (Filevine, Lawmatics, PracticePanther, MyCase, LawPay) plus pilot/evaluation of the two Clio community MCPs. Plus the citation-refusal trust-ceiling layer the functional doc already specified.

### Real estate executive summary

- **MLS access reality.** All four MLS data paths (Bridge, RESO, Spark, Trestle) require the operator to be a licensed real-estate agent or contracted broker subscriber of a specific MLS — API key alone insufficient. Trestle adds $85/mo platform fee + per-MLO license. Treat MLS as a per-customer provisioning step.
- **CRM coverage is thin.** Composio covers Follow Up Boss only (99 tools, GA). The other five RE CRMs (Lofty, kvCORE, BoomTown, Sierra, Real Geeks) — all public APIs, all BUILD. Prioritize by client demand.
- **Transaction management.** Dotloop is the cleanest public API and best first BUILD target. DocuSign Rooms is documented but separate from eSignature. SkySlope contract-gated. Brokermint open. zipForm BLOCKED/defer.
- **SMS / TCPA.** Use Twilio official MCP. Since Feb 2025, US carriers block unregistered 10DLC traffic and TCPA opt-out must be honored within 10 business days (Apr 2025 FCC rule). **Any agent-initiated SMS needs verified A2P 10DLC brand + campaign registration before launch — bake into client onboarding.**

## Ship readiness by customer profile

The AI Employee targets any business that can pay and benefit, regardless of size. Ship readiness is determined by the customer's **tool stack**, not by their revenue. A NetSuite manufacturer is shippable today on Composio whether they're $5M or $500M; a QuickBooks Desktop manufacturer needs a Conductor bridge whether they're $1M or $20M. Below is the ship picture organized by the tools customers actually run.

### Marketing agencies — **shippable today, zero BUILD**

**Modal stack:** Slack + (Asana / ClickUp / Monday) + (Harvest / Toggl) + Google Workspace + (Meta Ads / Google Ads / LinkedIn Ads) + GA4 + QuickBooks Online + HubSpot CRM + Google Drive / Dropbox + Canva + Fireflies (or Fathom / Granola).

**Connector status:** All COMPOSIO except Float (official MCP) and Meta Ads (vendor MCP preferred). Verified.

**BUILD work to ship:** Zero. The entire modal stack is Composio or official vendor MCP.

**Real frictions (vendor-side, not ours):** Google Ads developer-token approval and LinkedIn Marketing API app review are gates that hit us on any path. Plan a few days into onboarding for these.

## What this means for SMD's customer-zero

SMD's own ops naturally exercise a marketing-agency-shaped subset of skills: inbox triage, status assembly, AR-chase, scope-flagging, calendar coordination. These exercise zero of the Tier-1 BUILDs. **Customer-zero deployment runs entirely on Composio + native MCP**, no BUILD work required for SMD's own use.

The Tier-1 BUILDs (LawPay, Dotloop, Fishbowl, ShipStation, Spark API, Acumatica, Adobe Sign, SPS Commerce) get tested in the SMD deployment against synthetic fixtures — we won't have real Clio matters or real Fishbowl inventory in SMD's environment. The fixtures generate the same shape of data the agent would see in a real customer instance.

When the first paid beta lands, the relevant Tier-1 BUILDs become production code against the customer's live tools. Customer-zero stays as the regression-test bed: every new skill or wrapper update runs against SMD's instance first.
