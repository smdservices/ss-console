Architecture Decision Records (ADRs) capturing strategic and technical decisions made during the SMD Services platform build.

> **Looking for the substantive decision corpus?** The 43+ numbered go-to-market decisions (buy box, scope, pricing, assessment, distribution, delivery) live in [decision-stack.md](./decision-stack.md). The numbered ADRs below capture narrower architectural choices.

- [0016-honcho-disposition.md](./0016-honcho-disposition.md) - Honcho disposition: mirror, don't gate; tuned native configuration; conclusions mirrored to D1 `persona_observations` with provenance and evidence_status; TTL archival; Captain dismissal triggers physical DELETE from Honcho (**rewritten 2026-05-24**)
- [0017-skill-curator-disposition.md](./0017-skill-curator-disposition.md) - Skill Curator disposition: trust Hermes-native skill creation; `skill_manage` enabled in customer profiles; mirror to D1 `agent_skills_inventory` for Captain visibility (**rewritten 2026-05-24**)
- [0018-gepa-disposition.md](./0018-gepa-disposition.md) - GEPA self-evolution disposition (**superseded 2026-05-24** — GEPA not present in Hermes upstream; original boot-check verified a non-existent subsystem)
- [0019-customer-yaml-to-profile-config-translation.md](./0019-customer-yaml-to-profile-config-translation.md) - customer.yaml → per-profile Hermes config translation: `hermes-smd bootstrap` CLI; deterministic, idempotent; customer-sync sidecar polls R2 with structural-vs-non-structural change classification
- [0020-connector-strategy.md](./0020-connector-strategy.md) - Connector strategy: MCP-first where vendor or vetted-community server exists; BUILD only when no acceptable MCP (Composio retired 2026-05-30 — we connect to MCPs directly)
- [0021-leverage-hermes-native-primitives.md](./0021-leverage-hermes-native-primitives.md) - Leverage Hermes native primitives: `execute_code` for batch-loop skills, `delegate_task` for compound PI workflows, no-agent cron with `suppressed_wake` audit, skill bundles, webhook gateway via `pre_gateway_dispatch`, `ms_graph` BUILD retirement to MCP
- [0022-vertical-pack-architecture.md](./0022-vertical-pack-architecture.md) - Vertical pack architecture + time-machine substrate: vertical manifest schema, customer.yaml extension fields, skill body persistence, materialization history
- [0023-operator-per-customer-observability.md](./0023-operator-per-customer-observability.md) - Operator per-customer observability: compose existing specs + add Sentry, heartbeat, fleet view, alert routing
- [0024-hermes-consumption-and-update-cadence.md](./0024-hermes-consumption-and-update-cadence.md) - Hermes consumption and update cadence: upstream SHA-pin (`v{date}@{sha}`), golden base image in GHCR, track-vs-deploy with one blessed fleet version, two clocks (operational weekly / strategic quarterly); **supersedes the fork half of [ADR 0015](./0015-hermes-fork-vs-upstream.md)**
- [0025-autonomy-ceilings-configurable-exposure-vs-initiation.md](./0025-autonomy-ceilings-configurable-exposure-vs-initiation.md) - Autonomy ceilings are configurable: split autonomy-of-initiation from autonomy-of-exposure, expressed per action-class, enforced in code, audited, agent-never-self-raises; reviewer-as-sender retained as default + vertical-pack-lockable floor (**amends [ADR 0005](./0005-reviewer-as-sender.md)** — declassifies its "architectural, not configurable" holding)
- [0026-config-surface-is-a-security-boundary.md](./0026-config-surface-is-a-security-boundary.md) - The configuration surface is a security boundary: every autonomy-affecting config change is principal-authenticated, durably persisted, immutably audited, and floor-checked; the agent can never raise its own ceiling (companion to ADR 0025)
- [0027-inbound-trust-boundary.md](./0027-inbound-trust-boundary.md) - Inbound trust boundary: untrusted external content is provenance-attributed and structurally separated from the instruction channel before reaching the engine; inbound text can never drive a privileged action; maintained adversarial-injection corpus in CI
- [0028-outbound-integrity-gates-provenance-and-voice.md](./0028-outbound-integrity-gates-provenance-and-voice.md) - Outbound integrity gates: provenance (no-fabrication) and voice fidelity run on live output, not just boot/synthetic tests; fail-closed; the audit's sharpest next target
- [0029-workforce-model-inter-employee-mediation.md](./0029-workforce-model-inter-employee-mediation.md) - Workforce model (direction): ceilings transitive and monotonically non-increasing under delegation, accountability preserved end-to-end, isolation-by-default within a workforce; implementation deferred to multi-employee SKU (extends [ADR 0011](./0011-multi-persona-per-customer.md))
- [0030-control-plane-human-principal-surface.md](./0030-control-plane-human-principal-surface.md) - The control plane: the principal's single governing surface (review, memory control, authority/config, lifecycle) under one auth + audit guarantee; the agent can only propose, never self-govern
- [0031-content-sensitivity-send-floor.md](./0031-content-sensitivity-send-floor.md) - Content-sensitivity send floor: under an autonomous external-send ceiling, message bodies touching money/contract/scope/legal are downgraded to draft-for-review; content-derived floor on top of the ADR 0025 action-class ceiling (**amends [ADR 0025](./0025-autonomy-ceilings-configurable-exposure-vs-initiation.md)**)
- [0032-inbound-webhook-architecture.md](./0032-inbound-webhook-architecture.md) - Inbound webhook architecture: front-door gate (Svix signature verification), native-adapter routing into the Hermes webhook adapter, and deferred hardening (DMARC gate, durable idempotency, send-caps)
- [0033-telegram-channel-native-polling.md](./0033-telegram-channel-native-polling.md) - Telegram channel via Hermes native polling adapter: env-enabled, mandatory user allowlist (fails closed on empty), DM-only
- [0034-operator-product-naming.md](./0034-operator-product-naming.md) - Operator: product naming + capability realignment — renames "Operator" → "Operator" to match the autonomy posture (ADR 0025/0031); humans-as-operators and the `operator` RBAC enum retained; **supersedes [ADR 0004](./0004-productized-operator-offering.md) §"Service name"** and **amends [ADR 0013](./0013-operator-positioning-doctrine.md)** (brand name only; doctrine stands)
